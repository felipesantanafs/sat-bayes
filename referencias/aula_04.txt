Modelo de Erdös-Renyi
▶Modelo de grafo aleatório ER (G(n, p)): dados n nós, cada
ligação (não direcionada) possível se forma com probabilidade
independente p ∈(0, 1).
▶VANTAGENS: (i) Benchmark matemático simples para
analisar a formação de redes, (ii) Como veremos, este modelo
será uma ferramenta fundamental para fornecer as bases para
a compreensão da difusão em uma rede.
▶DESVANTAGEM: A maioria das redes sociais e econômicas
apresenta clustering, homofilia e distribuições de grau
específicas. Portanto, a independência não é uma boa
hipótese.

Modelo de Erdös-Renyi: Thresholds e Transições de Fase
▶Embora possa ser difícil determinar a probabilidade exata de
que alguma propriedade seja satisfeita para um dado n fixo,
muitas vezes é muito mais fácil determinar se essa
probabilidade converge para 1 ou 0 quando fazemos n tender
ao infinito.
▶Assim, permitimos que p seja uma função de n e perguntamos
se a probabilidade de que a rede realizada possua determinada
propriedade converge para 0 ou 1 quando n →∞.
▶Representamos a probabilidade de formação de uma ligação
como uma função de n, denotada por p(n).
▶É bastante natural que a probabilidade de formação de uma
ligação entre dois nós varie com o tamanho da população.
▶Por exemplo: se quisermos manter o grau médio constante à
medida que o número de nós cresce, precisamos de p(n) ∝1

Modelo de Erdös-Renyi
Resumo
▶O modelo ER é o modelo de grafo aleatório mais simples. A
hipótese fundamental é a formação independente das ligações.
▶O modelo ER é tratável, mas apresenta algumas características
pouco realistas, como clustering muito baixo. Ainda assim, é um
benchmark importante e um ponto de partida.
▶Uma característica fundamental do modelo ER é a existência de
fenômenos de threshold, como thresholds para o surgimento de um
componente gigante ou para o surgimento da conectividade.
▶No modelo ER, há apenas componentes pequenos ou um
componente gigante e muitos componentes pequenos.
▶Compreender o tamanho e a estrutura do componente gigante
(quando ele existe) é frequentemente importante, por exemplo, para
estudar difusão ou o comprimento médio dos caminhos.

Modelo de Ligação Uniforme
▶Antes de estudar o modelo de ligação preferencial, estudamos
uma variação dinâmica do modelo ER, na qual os nós surgem
ao longo do tempo e, quando surgem, formam m ligações com
nós existentes, escolhidos uniformemente ao acaso.
▶Nós mais antigos possuem graus esperados maiores.
▶Entretanto, como as ligações são formadas aleatoriamente,
apenas nós muito antigos possuem graus muito maiores que a
média.
▶Assim, o modelo de ligação uniforme é um modelo dinâmico
de formação de redes, mas não gera uma distribuição de grau
de lei de potência.

Modelo de Ligação Uniforme
Elementos
Os nós surgem ao longo do tempo e, quando surgem, formam
aleatoriamente ligações com nós existentes.
▶Indexe os nós por sua ordem de nascimento, de modo que o
nó i surge na data i, para i = 0, 1, . . ..
▶Ao surgir, um nó forma m ligações não direcionadas com nós
existentes. Seja di(t) o grau do nó i no tempo t.
▶Consideramos uma versão conveniente deste modelo em que
di(t) = m para todo t > m, e, para t ≤m, o novo nó se
conecta a todos.
▶Equivalentemente, o primeiro novo nó surge no tempo
t = m + 1, e a rede preexistente nesse momento é a rede
completa com m nós.

Modelo de Ligação Preferencial
Resumo
▶Modelos dinâmicos de formação de redes acrescentam
realismo ao modelar como as redes se formam ao longo do
tempo.
▶Se novos nós formam ligações uniformemente ao acaso, o
processo gera redes de cauda fina, semelhantes às redes ER.
▶Se novos nós se conectam aos nós existentes
proporcionalmente aos seus graus, o processo gera redes com
distribuições de grau de lei de potência.
▶A formação dinâmica de redes com ligação preferencial é uma
explicação para distribuições de grau de lei de potência, como
as observadas entre páginas da web, redes de citações e redes
de amizade.
